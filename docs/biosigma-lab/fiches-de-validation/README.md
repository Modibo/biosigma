# Fiches de validation

Un dossier par élément et par version. Les fichiers `FV-PREP-…` sont des **brouillons préparés par l'auteur** : ils ne valident rien tant que le validateur scientifique (Dr Modibo Mouctar Coulibaly) ne les a pas complétés et signés. Après signature, la fiche reçoit un numéro `FV-AAAA-NNN`, l'original signé est archivé (hors dépôt si nécessaire) et une `ValidationRecord` correspondante est ajoutée au code (voir `../gouvernance-validation.md`).
